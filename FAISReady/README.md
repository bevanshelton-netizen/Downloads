# FAISReady launch package

South African RE5/RE1 regulatory-exam preparation platform for individuals and companies.

Commercial positioning: premium-quality preparation at an affordable price.

- RE5 Complete Prep: R299 / 90 days
- RE1 Complete Prep: R399 / 90 days
- RE5 + RE1: R549 / 120 days
- Companies: volume candidate licensing

This branch is the deployment checkpoint for FAISReady. See `DEPLOYMENT_HANDOFF.md`, `LAUNCH_CHECKLIST.md` and `REGULATORY_CONTENT_MANIFEST.md`.
