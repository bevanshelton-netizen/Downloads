What are you preparing to drive?

We use the familiar licence names while mapping you to the official learner category.

Official learner categories are Code 1 (motorcycles), Code 2 (vehicles up to 3,500 kg) and Code 3 (vehicles over 3,500 kg). Learner Driver SA keeps 08/10/14 labels because learners commonly recognise them.
