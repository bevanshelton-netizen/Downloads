# DOXA-SURE on-site Help Desk launch

This release removes the personal phone number and WhatsApp dependency from the public DOXA-SURE site. The public funnel now stays on-site: Free Asset Risk Check → automated Help Desk → pilot service explanation / professional escalation where needed.
