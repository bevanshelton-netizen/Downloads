# DOXA-SURE WhatsApp conversion path

The zero-cost founding pilot now routes warm prospects to a human conversation without requiring a paid CRM, SMS gateway or checkout integration.

## Public flow
1. Visitor lands on the human-centred pilot page.
2. Visitor can start the Free Asset Risk Check or choose Talk to a human.
3. Risk-check result is Green, Amber, Red or Critical.
4. The result button prepares a WhatsApp message containing only the result and selected asset category.
5. Founding offers prepare separate WhatsApp enquiries for the R199 Rescue Readiness Pack and R99/month DOXA-SURE Shield.
6. No banking login, PIN or password is collected.

## Human handling
Keep the first WhatsApp response simple: acknowledge the person, confirm the asset category and urgency, then request only the minimum factual information needed for the pilot intake. Urgent legal/enforcement situations should be routed toward suitably qualified professional assistance without implying that DOXA-SURE has stopped any legal process.

## Bootstrap rule
Do not add a paid CRM, WhatsApp API, SMS integration or payment automation until the manual funnel has produced enough real demand to justify the cost.
