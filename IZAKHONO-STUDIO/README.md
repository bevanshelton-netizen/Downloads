# IZAKHONO STUDIO

**Design fast. Brand loud. Share anywhere.**

IZAKHONO STUDIO is a free-first browser design platform for social posts, posters, flyers, stories/reels, thumbnails and branded campaign assets.

## Working v1 features
- Loud, visible platform identity and responsive editor.
- Social/campaign size presets: Instagram, Stories/Reels, Facebook, LinkedIn, YouTube and A4.
- Editable text layers with striking font choices, sizing, alignment and colour controls.
- Image upload and drag positioning.
- Template starters for launches, offers, music, education and automotive campaigns.
- Browser-side `Instant Design` starter that converts a short brief into a matching design direction without requiring a paid API.
- Brand name, accent colour and background controls.
- Duplicate/delete layer actions.
- PNG export in-browser.
- Native mobile sharing when supported, with PNG fallback.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

The generated `dist/` folder can be hosted on a static/free-tier host or IZAKHONO infrastructure.
