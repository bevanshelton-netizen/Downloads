# IZAKHONO GAMER STUDIO

Gamer Studio is a first-class module inside the USD $5/month IZAKHONO Creative Suite. It is not a separate subscription.

## Working v1
- Stream overlay canvas.
- YouTube gaming thumbnail canvas.
- Esports card canvas.
- Short/Reel gaming cover canvas.
- Gamer tag, team/channel and message controls.
- Visual themes.
- Optional local gameplay/hero-image import.
- Stream facecam and chat frames.
- PNG export.
