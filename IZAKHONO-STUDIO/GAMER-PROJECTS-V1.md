# IZAKHONO GAMER PROJECTS V1

Gamer Studio v0.5 adds a portable project layer without making the browser depend on a cloud account.

## Working
- Project name.
- Save up to 12 gamer/team presets on the current device.
- Load/delete saved projects.
- Export a portable `.izgamer.json` project.
- Import a portable project file.
- Preserve format, theme, gamer tag, team/channel, message, sponsor, facecam and chat settings.
- Gameplay/hero imagery stays local and is intentionally not embedded in the v1 project file.
- Sponsor/partner field renders into the creative.

## Privacy / lock-in rule
Projects are local-first. The portable JSON format remains readable and exportable. A future IZAKHONO account sync layer must be optional and must not remove local project portability.
