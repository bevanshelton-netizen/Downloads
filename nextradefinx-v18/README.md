# NexTradeFinX V18 — First Learner Onboarding

V18 defines the first complete human onboarding flow for the controlled beta.

It gates access on:
- approved invite
- verified email
- conservative 18+ beta confirmation
- versioned Terms / Privacy / Risk acknowledgement
- language choice
- experience level
- learning goal
- paper-only acknowledgement
- no-profit-promise acknowledgement

After passing, the learner can create a Learning Passport and enter a level-appropriate first session.
