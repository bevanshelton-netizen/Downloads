# KORA AFRICA

KORA AFRICA is the regional ecosystem layer for KORA, providing a structured foundation for country, territory, language, currency, regulatory-context and service configuration.

## Architecture

`KORA AFRICA → KORA ID / LEARN / WORK / PAY / NAV / MEDIA / AI`

KORA AFRICA does not replace national government systems or regulated institutions. It provides the KORA control-plane context required to localise experiences safely and consistently.

## Core domains

- countries and territories
- regions and cities
- languages and locale preferences
- currencies and monetary display
- licence and transport jurisdiction references
- local service availability
- market and operating-region configuration
- emergency/public-service references
- country-specific product policies
- African-first discovery and routing

## Principle

Africa is not a single market configuration. Each jurisdiction retains its own rules, languages, services and institutional boundaries while sharing a common KORA platform architecture.
