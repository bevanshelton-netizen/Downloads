# IZAKHONO Business Command

Portfolio launch surface for the 54-business IZAKHONO portfolio.

## Operating rule
ONE SENTENCE → ONE BUSINESS.

Each venture must move through: offer → customer → acquisition → payment → delivery → retention → verified revenue.

## Deployment truth
This repository surface is a portfolio operating shell. A business is only considered production-live when its own application, critical workflows, required integrations, legal/regulatory requirements and public reachability have been independently verified.

## Source
`../businesses/businesses.json` is the portfolio catalogue.
