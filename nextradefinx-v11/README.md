# NexTradeFinX V11 — Learning Passport

V11 makes NexLearn persistent. A learner can return later and continue from the same educational stage without turning NexTradeFinX into a brokerage account.

## What V11 adds

- learner passport profile
- language and experience preferences
- learning-goal selection
- append-only learning-event history
- quiz-attempt and paper-session records
- readiness snapshots
- educational badge issuance when readiness is earned
- data-minimisation and deletion boundaries

## Product boundary

The Learning Passport is not a brokerage account, KYC profile, suitability assessment or investment-advice profile. It stores only what is needed to deliver and measure the educational experience.
