# KORA WORK

KORA WORK is the work, opportunity and productivity layer of the KORA ecosystem.

## Architecture

`KORA ID → KORA WORK → KORA PAY → KORA AI`

KORA WORK connects people, businesses and opportunities through a portable work profile and structured opportunity workflow.

## Core domains

- worker and professional profiles
- skills, qualifications and experience
- jobs, projects, gigs and assignments
- applications and candidate status
- employer/work-provider records
- work readiness and matching metadata
- task and engagement lifecycle
- links to KORA LEARN for training/readiness
- links to KORA PAY for verified commercial/payment states
- KORA AI assistance for search, matching and workflow support

## Ownership principle

KORA owns the user experience, work-domain model, matching rules, workflow state and integration control plane. External job boards, payroll providers, identity providers and payment partners are adapters, not the core KORA system.

## Safety and trust boundary

KORA WORK must not imply employment, income, qualification, background-check, immigration or regulatory outcomes that have not been verified. Opportunities and credentials carry explicit verification state, and payment status is kept separate from work completion.
