# IZAKHONO BUILDER — Sovereign v1.0.0

Owner-controlled, local-first application factory.

The Builder core does not require Cloudflare, Vercel, Supabase, GitHub, a VPS, paid database or paid object storage. It runs on Node.js with local files, a local project registry, local workspaces, browser preview and local packaging.

Windows: extract the release and double-click `START-IZAKHONO-BUILDER.cmd`.

Core capabilities: project registry, module selection, generated application workspaces, local preview, local data store, package/export workflow, and provider-neutral scaffolds for CRM, auth, files, payments, email, admin, analytics, marketplace, learning, video and AI.

Commercial truth: Payments is an integration/ledger scaffold rather than a payment processor; Email is an outbox scaffold rather than an email delivery network; AI is a provider-neutral adapter boundary rather than a bundled foundation model.

GitHub is optional backup/source control only. Future owner-controlled layers can include IZAKHONO SOURCE, RUN, DATA, EDGE and DEPLOY without replacing the Builder core.
