# Lebo & Jabu Episode 1 Finishing Stack

This owned IZAKHONO worker turns an approved Episode 1 guide picture into a richer **finishing package** without pretending guide assets are final performances.

It creates:
- a procedurally composed, original **KORA KIDS Adventure Theme — Guide**;
- six consistent **Jabu guide sound cues**: hello, question, proud, happy, sneeze and goodbye;
- a polished 16:9 episode guide with the original guide theme mixed underneath;
- a 1080x1920 vertical Short guide using a blurred-background safe-center treatment;
- a 1280x720 thumbnail guide;
- SHA-256 checksums and finishing QC.

The theme and Jabu sounds are reproducible guide assets generated inside IZAKHONO. They are not final cast/music/SFX masters and cannot satisfy the existing mastering/release rights gates.

Final release still requires real approved voice performance, approved Jabu sound design, original music performance/master, human visual QC, mastering and explicit release authorization.
