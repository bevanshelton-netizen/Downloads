# IZAKHONO DOMAINS / EDGE v1.6 two-node proof launchers

These launchers are the Windows-side wrappers for the hardened v1.6 owner-proof kit.

They deliberately use the non-production child zone `edge-test.izakhonoafrica.co.za` and do not authorize production nameserver changes.

Required binary bundle beside the primary launcher: `IZAKHONO-CLOUD-EDGE-v1.6-HARDENED.zip`.

Production cutover remains locked until primary, independent secondary DNS, third-network UDP/TCP 53, TLS, backup/restore, rollback and failure-recovery proofs pass.
