# NexTradeFinX V13 — Controlled Beta & Consent

V13 adds the account-lifecycle and consent controls needed before external learners can be invited into the education/paper-trading product.

## Adds
- invite-only beta eligibility gate
- verified-email requirement
- conservative 18+ beta confirmation
- versioned Terms / Privacy / Risk acknowledgement receipts
- append-only consent storage
- learner-visible beta access status with server-only approval
- user-initiated deletion requests with server-only auth deletion

## Boundary
No live execution, client funds, leverage, brokerage account, suitability assessment or personalized advice is enabled by V13.
