# IZAKHONO GROWTH OS v2 — visual prototype archive

This folder is retained as the visual prototype/reference that informed the premium v2 interface. It is **not** the production Growth OS application.

Production source now lives in `izakhono-growth-os/`, where the UI is combined with server APIs, provider readiness, measurement ingestion, owned DATA integration, approval guardrails and the owner-host deployment path.

Production topology:

```text
ISN-01 -> IZAKHONO CODE -> IZAKHONO RUNTIME -> IZAKHONO EDGE -> growth.domains.izakhonoafrica.co.za
```

Use `START-GROWTH-OS-V2-ON-IZAKHONO.cmd` for the owner-host deployment. Vercel is not required.
