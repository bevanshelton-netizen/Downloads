## Product rules
1. CAPS/NCS is treated as the national curriculum framework. Province selection does not imply nine different curricula.
2. Province context may drive language, implementation resources, schedules and provincial materials.
3. Prescribed works are represented as metadata and learning maps. Full copyrighted books are not reproduced without permission/licensing.
4. Official DBE resources are linked rather than copied wholesale.
5. Practice content is original unless an authorised public/official paper is being linked or lawfully reproduced.

## Literature engine
For each language and prescribed work:
work -> genre -> section/chapter -> characters -> themes -> context -> literary devices -> lawful excerpts -> original explanation -> exam questions -> essay practice -> rubric-guided feedback.

## Learner engine
province -> language/subject selection -> next exam -> study mission -> practice -> marking -> misconception -> re-teach -> mastery -> spaced revision.
