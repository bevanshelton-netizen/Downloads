# IZAKHONO OBJECT NODE

Owned object/file storage for IZAKHONO platforms.

## V1 capabilities

- buckets with quotas;
- PUT / GET / HEAD / DELETE objects;
- prefix listing;
- SHA-256 content-addressed blobs;
- physical deduplication;
- metadata in SQLite;
- ETag support;
- per-object content types;
- service-key authentication;
- local garbage collection;
- systemd deployment;
- zero runtime npm dependencies.

## Typical uses

- ad creatives;
- product photos;
- videos;
- documents and certificates;
- exports;
- release artifacts;
- backups generated by IZAKHONO services.

## Topology

Applications → private OBJECT NODE API → metadata SQLite + owned disk/NAS

The service binds to loopback by default. Public downloads should later be mediated by an authenticated application endpoint or a dedicated signed-download layer at EDGE NODE.

## Storage cost

There is no hosted object-storage subscription in the software. Capacity comes from disks/NAS hardware you own, plus normal electricity, connectivity and backup costs.
