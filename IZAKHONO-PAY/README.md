# IZAKHONO PAY

Owner-controlled merchant-first payment orchestration platform.

## v0.1 scope

- merchant application + visible onboarding status
- sandbox merchant provisioning
- hashed merchant API keys
- payment links and payment intents
- transaction and ledger APIs
- structured support tickets
- refund-request workflow
- audit trail
- sandbox payment completion for integration testing
- ZAR-first design
- no raw card capture/storage
- no custodial funds handling

## Core principle

IZAKHONO PAY owns the merchant experience and payment state machine while licensed acquiring/payment rails remain replaceable adapters. This allows us to improve merchant service without pretending to be a bank or licensed card acquirer before the required South African authorisation and banking arrangements are complete.

The validated v0.1 release bundle is stored on this branch as a base64 ZIP for recovery/deployment.
