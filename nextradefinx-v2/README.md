# NexTradeFinX V2 staging

NexTradeFinX is a beginner-first, multilingual AI financial-market education, market-intelligence, risk-coaching and paper-trading platform.

## Current V2 direction

- Learn → Ask → Practise → Check Risk → Trade Later journey
- Beginner / intermediate / advanced explanation modes
- Probability-based forecast UX with explicit no-trade outcomes
- Plain-language “Explain this simply” flow
- Virtual paper trading and NexRisk position sizing
- Prediction ledger and model-governance architecture
- Provider-neutral adapters for market data, KYC/FICA, brokerage, custody and payments
- Real-money execution remains disabled until regulated partner and model-validation gates are complete

The working V2 source package is being kept separate while NexTradeFinX gets its own dedicated repository. This branch reserves the staging path without mixing the project into production code for other ventures.
