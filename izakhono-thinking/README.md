# IZAKHONO THINKING — Advanced Decision Intelligence

A founder-controlled thinking and execution workspace for the IZAKHONO portfolio.

## Current prototype

- `owner.html` — unlimited founder command layer across 12 portfolio rooms.
- `index.html` — structured Decision Room with six thinking modes.
- Evidence/assumption separation.
- Alternative framing and red-team warnings.
- Clarity, evidence, risk-readiness and actionability indicators.
- Local session continuity and downloadable decision briefs.
- Responsive, dependency-free static build.

## Meaning of “Unlimited”

The product has no artificial founder-side mode locks, seat tiers or feature gates. It does **not** claim that third-party APIs, hosted compute, storage or model tokens are physically unlimited. Capacity and costs must be shown truthfully.

## Safety and governance

The interface provides concise decision support and action records, not private model chain-of-thought. Human owners remain accountable. High-impact legal, medical, financial and engineering decisions require qualified review and verified evidence.

## Run

Open `owner.html` in a browser. Choose a portfolio room, then use the Thinking Cycle and export a brief.
