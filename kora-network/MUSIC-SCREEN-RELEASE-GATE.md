# KORA MUSIC-SCREEN RELEASE GATE

A video being uploaded does not make it release-ready.

Before a KORA music-screen production can be commercially published, the workflow must resolve:

## Rights
- creator/submitter authority;
- composition/music rights;
- sound-recording/master rights;
- performer/contributor releases;
- visual material ownership/licences;
- archive/third-party footage;
- still photography;
- interview releases where applicable;
- script/story rights for scripted/biographical works;
- cast/location permissions;
- active disputes.

## Audience safety / classification
- proposed age rating;
- content warnings where appropriate;
- minors/sensitive participants;
- platform content-policy review.

## Advertising / sponsorship
- sponsor relationship disclosed;
- brand integration approved;
- paid/editorial distinction not misleading;
- restricted-category advertising reviewed.

## Accessibility
For long-form/public flagship content, KORA should strongly prefer:
- captions/subtitles;
- transcript;
- audio description where materially appropriate and feasible;
- readable metadata/title/description;
- keyboard-accessible player controls.

The database records accessibility state instead of pretending every production has identical accessibility needs.

## Archive evidence
Documentary, revival, tour and biographical content should retain evidence references for archive footage/stills/licences.

## Publication truth
The release gate is independent of:
- upload completion;
- payment setup;
- creator popularity;
- sponsor pressure.

Commercial urgency never overrides unresolved ownership or serious safety blockers.
