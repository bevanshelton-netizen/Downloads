# IZAKHONO MARKETING OS™

Unified advertising and marketing operating system for African-first, global-ready growth.

## Architecture
- **System of record:** IZAKHONO-owned infrastructure / NODES01
- **Security:** FORTRESS integration boundary
- **Social adapter:** Metricool (connected brand baseline: Shelton Marketing / brand 7233518)
- **External platforms:** adapters only; core product remains portable
- **Deployment:** Docker/Compose ready for NODES01

## Product layers
1. Ad Intelligence
2. Creative Factory
3. Campaign Engine
4. Social Command
5. Paid Ads Command
6. Analytics
7. Brand OS
8. AI Marketing Agent

## Development rule
Build the product so external providers can be replaced without rewriting the core business logic.
